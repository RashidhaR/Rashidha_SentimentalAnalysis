# Voice Sentiment Analysis

## 📊 Project Overview

A Python-based voice sentiment analysis application that allows users to log in, record or upload voice recordings, convert speech into text, and analyze the sentiment of the spoken content.

The application combines a Tkinter-based graphical interface, MySQL authentication, speech recognition, audio processing, and NLTK VADER sentiment analysis.

## 🔄 Application Workflow

Login
→ MySQL Authentication
→ Admin Interface
→ Record / Upload Audio
→ Speech-to-Text
→ Sentiment Analysis
→ Positive / Negative / Neutral Result

## 🔍 Key Features

- User login authentication using MySQL
- Tkinter graphical user interface
- Voice recording with selectable duration
- Upload and analyze existing WAV audio files
- Speech-to-text conversion
- Sentiment analysis using NLTK VADER
- Positive, Negative, and Neutral sentiment classification
- Audio file processing and conversion
